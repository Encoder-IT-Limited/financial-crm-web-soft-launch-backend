Inventory API sample for frontend (Products / Warehouses / Stock Transfers)
================================================================================
Updated: 2026-08-26
Base URL (VPS): http://147.93.108.61:4001/api/v1
Prefix: /inventory/...  (NOT bare /products or /stock-transfers)

Auth
----
Authorization: Bearer <accessToken>
X-Tenant-Subdomain: demo
When calling the VPS by IP, also set Host: 147.93.108.61

Envelope
--------
Success: { "success": true, "data": <payload>, "meta"?: { ... } }
Error:   { "success": false, "error": { "code", "message", "details?" } }

Login (to get token)
--------------------
GET  /auth/csrf
POST /auth/login
Body: { "email": "owner@demo.local", "password": "SecurePass123" }
Token: response.data.tokens.accessToken

================================================================================
PRODUCTS
================================================================================

List (optional filters + pagination)
GET /inventory/products
Query (all optional):
  search       - name / sku / barcode
  status       - ACTIVE | INACTIVE
  categoryId   - uuid
  barcode      - exact barcode
  page         - number (if set WITH pageSize → server pagination)
  pageSize     - 1..100

If page/pageSize omitted → returns ALL products (safe for POS catalog).

Example:
GET /inventory/products?page=1&pageSize=20&search=usb&status=ACTIVE

Response example:
{
  "success": true,
  "data": [

      "subcategoryName": "Cables",
      "unitId": "...",
      "unitName": "Piece",
      "unitSymbol": "pcs",
      "costPrice": 2.5,
      "sellingPrice": 5,
      "taxRate": 5,

      "reorderLevel": 10,

Get one
GET /inventory/products/:id

Create
POST /inventory/products
Body example:
{
  "sku": "ELEC-001",
  "barcode": "6281000000012",
  "name": "USB Cable",
  "description": "USB-C charging cable",
  "categoryId": "<uuid>",
  "unitId": "<uuid>",
  "costPrice": 2.5,
  "sellingPrice": 5,
  "taxRate": 5,
  "minimumStock": 5,
  "maximumStock": 100,
  "reorderLevel": 10,
  "trackBatch": true,
  "status": "ACTIVE"
}

Update
PATCH /inventory/products/:id
Body: any subset of create fields (same shape). Example:
{
  "name": "USB Cable Updated",
  "maximumStock": 500,
  "status": "ACTIVE"
}

Delete
DELETE /inventory/products/:id
Success: { "success": true, "data": { "id": "...", "deleted": true } }
If product has stock history / sales / transfers:
  409 PRODUCT_IN_USE → deactivate instead:
  PATCH /inventory/products/:id  { "status": "INACTIVE" }

Notes for UI columns:
  name, sku, categoryName, subcategoryName, unitSymbol/unitName,
  onHand (current stock), minimumStock, maximumStock, status

      "quantity": 12,
      "damagedQuantity": 1,

Warehouse has no dedicated contact field — location is `address`.

Create
POST /inventory/warehouses
{
  "name": "Main Warehouse",
  "code": "WH-01",
  "address": "Dubai",
  "status": "ACTIVE"
}

Update
PATCH /inventory/warehouses/:id
{
  "name": "Main Warehouse",
  "code": "WH-01",
  "address": "Dubai Marina",
  "status": "ACTIVE"
}
status: ACTIVE | INACTIVE

Delete
DELETE /inventory/warehouses/:id
Success: { "id", "deleted": true }
409 if:
  WAREHOUSE_HAS_STOCK
  WAREHOUSE_HAS_TRANSFERS (open PENDING/APPROVED/DISPATCHED)
  WAREHOUSE_IN_USE (has movement history) → set status INACTIVE instead

UI columns: name, code, address (location), status, productCount, totalOnHand

================================================================================
STOCK TRANSFERS
================================================================================

List (filterable + paginated)
GET /inventory/transfers

Query:
  sourceWarehouse       OR fromWarehouseId      - uuid
  destinationWarehouse  OR toWarehouseId        - uuid
  status                - PENDING | APPROVED | DISPATCHED | RECEIVED | CANCELLED
  dateFrom              - ISO 8601
  dateTo                - ISO 8601
  search                - UUID → exact transfer id; otherwise warehouse name/code or product sku/name
  page                  - default behaviour: omit page+pageSize → all rows
  pageSize              - 1..100 (use with page for server pagination)

Example:
GET /inventory/transfers?sourceWarehouse=<uuid>&status=PENDING&page=1&pageSize=20&dateFrom=2026-01-01T00:00:00.000Z&dateTo=2026-12-31T23:59:59.999Z

Get one

Create

{
  "fromWarehouseId": "<uuid>",
  "toWarehouseId": "<uuid>",

POST /inventory/transfers/:id/receive

UI list columns: reference (id), source, destination, date, itemCount, status, createdBy
Reset page to 1 when filters change; keep filters in URL query string.

GET /inventory/reorder
Query: warehouseId?  (uuid — scopes on-hand to that warehouse)
Low-stock rule: ACTIVE and onHand <= max(reorderLevel, minimumStock)
suggestedQuantity = max(1, reorderLevel * 2 - stock)

Query: warehouseId?  (uuid)
